# 賃貸初期費用計算 v1.3.2

## v1.3.2

- 「その他月額費用」欄の各金額から、重複する「/月」表記を削除しました。
- 更新用リンク: https://ithiromu-hub.github.io/chintai-cost-calculator/chintai-cost-calculator.html?v=1.3.2

## v1.3.1

- 帳票上部の月額合計を削除し、その欄と下の行を「その他月額費用」に統合しました。
- 月次保証料・口座振替事務手数料など、前賃料や保証料の算定対象外にした月額費用も上部へ表示します。件数が増えた場合は欄を広げます。
- 月額費用欄の不規則な黄色の色分けをなくし、1つの淡黄色の欄にしました。
- 下部の表示を「① 契約金合計」「② 仲介手数料」に変更しました。
- 更新用リンク: https://ithiromu-hub.github.io/chintai-cost-calculator/chintai-cost-calculator.html?v=1.3.1

## v1.3.0

- 画像・PDFの契約金概算書を、見本のExcel帳票に合わせた黒罫線・薄黄色の入力欄・黄色の差引合計へ変更しました。
- 仲介手数料は明細から外し、下部の「② 仲介手数料」に1回だけ表示します。合計への加算も1回です。
- 礼金・敷金、当月日割の賃料・管理費、翌月分、火災保険・鍵交換代・保証会社の順に表示します。月次費用、ペット敷金、フリーレント、任意項目も合計と一致します。
- 「申込金（預り金）」を入力すると、受領済み金額を差し引いた金額を画面・画像・PDFに表示します。
- 「概算書プレビュー」で保存前に帳票を確認できます。A4に収まらない項目数は切り捨てず、出力時に案内します。
- 印刷時に入力画面の余白が残って空白ページが増える問題を修正しました。
- 更新用リンク: https://ithiromu-hub.github.io/chintai-cost-calculator/chintai-cost-calculator.html?v=1.3.0
- 検証: `node --test tests/*.test.mjs`

## v1.2.0

- iPhone/Safari・ホーム画面版を含め、認証アドオンなしで利用できます。
- 計算画面の必須端末認証を解除し、旧キャッシュ用の互換スクリプトも起動を妨げない形に更新しました。
- ページはオンライン時に最新を確認し、オフライン時は保存済みの画面を使用します。
- 旧キャッシュが残る場合は `chintai-cost-calculator.html?v=1.2.0` を開いてください。

## v1.1.0

- 固定IDの共通JDS端末認証アドオンへ利用可否を照会します。
- 個別ログイン画面は表示せず、元のタブを変更しません。

JDS反響システムの「業務改善ツール」から開くWeb版の初期費用計算ツールです。

## v1.0.2

- 初回起動時にPCユーザー名を入力し、接続元IP・端末ID・ツール版をJDS反響システムへ記録します。
- パスワード入力時・ページ起動時・15分ごとにJDSへ照合します。旧パスワード利用はJDSへ警告し、初回検知の24時間後に利用者への事前表示なしで停止します。
- パスワードはWebページ、localStorage、GitHubへ保存しません。
- この更新はDiscordへ通知しません。D-room NAVI対応の更新通知だけを別途送る運用です。

構文検査とサービスワーカーのキャッシュ更新は実施します。GitHub Pages上の初回認証は公開後に確認してください。
