# 賃貸初期費用計算 v1.1.0

## v1.1.0

- 固定IDの共通JDS端末認証アドオンへ利用可否を照会します。
- 個別ログイン画面は表示せず、元のタブを変更しません。

JDS反響システムの「業務改善ツール」から開くWeb版の初期費用計算ツールです。

## v1.0.2

- 初回起動時にPCユーザー名を入力し、接続元IP・端末ID・ツール版をJDS反響システムへ記録します。
- パスワード入力時・ページ起動時・15分ごとにJDSへ照合します。旧パスワード利用はJDSへ警告し、初回検知の24時間後に利用者への事前表示なしで停止します。
- パスワードはWebページ、localStorage、GitHubへ保存しません。
- この更新はDiscordへ通知しません。D-room NAVI対応の更新通知だけを別途送る運用です。

構文検査とサービスワーカーのキャッシュ更新は実施します。GitHub Pages上の初回認証は公開後に確認してください。
